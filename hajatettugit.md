1. Mitä tyhjän GitHub-repositorion sivulla näkyy?

GitHub näyttää ohjeet, joiden avulla repositorion voi yhdistää paikalliseen repositorioon.

2. Mitä git remote -v näyttää?

Komento näyttää etärepositorion osoitteet. nimi yleensä origin

3. Mitä tapahtuu, kun master-haara viedään GitHubiin?

Kun paikallinen master-haara pusketaan GitHubiin, sen talletukset tulevat näkyviin etärepositorioon.

opin, että github toimii etärepositoriona, johon paikallisen repositorion muutoksia voidaan viedä ja josta muutoksia voidaan hakea.Myös komentoja kuten fetch ja merge.
